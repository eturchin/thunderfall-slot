# Asset authorship

All eleven symbol SVGs and stormscape.svg are independently authored for Thunderfall: Crown, hammer, ring, five gems, orb, gate and Classic Wild. The Winter Olympus revision adds saturated gemstone facets, gold bevels and stronger silhouettes to the original SVG set. These code-authored assets are covered by this project's MIT license. No commercial slot artwork or proprietary reel data was copied.

PixiJS adds procedural particles/highlights/lightning; GSAP sequences actual engine moves. Web Audio synthesizes spin/drop/tumble/thunder/multiplier/scatter/bonus/retrigger/completion/big-win and ambient tones. No remote audio URLs or missing downloads. Sound requires interaction, has bounded voices, event throttling, separate saved music/SFX gain and cleanup.

Anton Regular and Cinzel Decorative Black are self-hosted under `frontend/public/assets/fonts/`. Both are distributed under the SIL Open Font License 1.1, with their upstream OFL texts alongside the font files. Sources: `https://github.com/google/fonts/tree/main/ofl/anton` and `https://github.com/google/fonts/tree/main/ofl/cinzeldecorative`. System sans-serif and Georgia remain fallbacks.

`frontend/public/assets/olympus-winter-v1.png` is an original background generated using the built-in imagegen tool for this project. The user-supplied commercial screenshot was a visual reference for the palette, typography and composition; it is not shipped as an application asset. Generation prompt and implementation details are recorded in `docs/OLYMPUS_VISUAL.md`.

No artwork/source was copied from the audited GitHub clones; a license file was not found in them. Public-domain algorithm attribution is in THIRD_PARTY_NOTICES.md.

Libraries retain upstream licenses, including GSAP's own standard license. Project MIT applies to original Thunderfall source/assets, not third-party packages. Inspect installed LICENSE/package metadata for redistribution. Test traces are actual local engine outputs, with no external artwork source.
